COMMON QUESTIONS

Before you
choose ComAp.

What is the difference between engine control and generator power management?

Engine control supervises the engine, including measurements, commands, alarms, and protection. Generator power management coordinates electrical sources and their breakers, including synchronisation and load sharing where required. Some projects need both functions and a defined interface between them.

Can I mix different ComAp controllers or replace an older model directly?

Compatibility is specific to the controller family, firmware, communication method, wiring, and operating sequence. A similar panel size does not establish compatibility. Share the existing models and configuration so a migration can be reviewed before hardware is selected.

Does every ComAp controller include load sharing or remote monitoring?

No. Features vary between controller families, software options, extension modules, and communication arrangements. InteliLite single-set control, InteliGen paralleling, and WebSupervisor cloud monitoring address different requirements. Confirm the complete configuration, licensing, and connectivity for your project.
